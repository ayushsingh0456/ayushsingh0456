### Hi, I'm Ayush Kumar Singh

**I'm a Business Analyst on healthcare and SaaS products.** I turn messy operational problems into requirements that engineers can build, QA can test and stakeholders can sign off.

I work across 15+ web and mobile products in healthcare, fintech, fitness, hospitality and marketplaces. I take them from the first client call to live deployment, covering:
- discovery and compliance research;
- BRDs, SRS documents and user stories;
- system and process diagrams;
- sprint coordination;
- UAT and change control.

#### How I work

**Business analysis**
- Requirement elicitation: interviews, workshops, observation
- Stakeholder management
- Gap analysis
- BRD, SRS and PRD
- User stories with Gherkin acceptance criteria
- Change requests with impact analysis, and recommendations
- Requirements traceability matrix (RTM)

**Modeling**
- Process flows and use cases
- Sequence and state diagrams
- ERDs
- System architecture
- Wireframes

**Delivery**
- SDLC from discovery to go-live and hypercare
- Agile and Scrum: backlog refinement, sprint planning, reviews and retrospectives
- Milestones, release plans and RAID logs
- UAT and test-case review
- API testing in Postman
- Incident and post-incident documentation

**Compliance exposure**
- HIPAA and BAA
- FCRA screening
- W-9 onboarding
- EU VAT and allergen rules

**Tools**
- Jira, Azure DevOps and Zoho Sprints
- Figma, Balsamiq, Lucidchart and draw.io
- Mermaid and PlantUML
- Postman, SQL and Excel
- Claude, GitHub Spec Kit and Amazon Kiro

**AI-assisted delivery**
- Spec-driven development: specs, plans and task lists for AI coding agents
- AI-assisted prototyping (vibe coding) to validate flows with stakeholders before build
